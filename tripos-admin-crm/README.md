# TripOS Admin CRM

Internal web application for owners, admins, sales, operations, finance, marketing, and support teams.

For TripOS v1, this app also contains restricted B2B agent workflows and DMC operations workflows. Those areas should be implemented as role-based sections, not separate frontend applications.

Recommended stack:

- Next.js
- TypeScript
- React Query or TanStack Query
- Shared UI package
- Shared validation package

Implemented views:

- Dashboard
- Leads
- Customers
- Quotations
- Itineraries
- Bookings
- Operations
- B2B Agents
- Agent Enquiries
- Agent Credit and Commission
- Payments
- Suppliers
- Reports
- Settings

Useful commands:

```bash
npm install
npm run dev
npm run build
npm run typecheck
npm run lint
```

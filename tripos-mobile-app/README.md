# TripOS Mobile App

React Native mobile application for customer and B2B agent experiences.

Capabilities:

- Persisted secure session storage
- Customer and agent navigation
- Itinerary view
- Voucher and document access
- Payment reminders
- Trip notifications
- Support chat
- Feedback
- API-backed records with offline fallback messaging

Useful commands:

```bash
npm install
npm run start
npm run typecheck
npm run lint
npm run test
```

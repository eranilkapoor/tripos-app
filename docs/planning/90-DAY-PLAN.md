# TripOS 90-Day Plan

## Days 1-15: Discovery

Interview 5 to 10 travel agencies and 3 to 5 DMCs.

Questions:

- How do leads arrive today?
- Who assigns leads?
- How are requirements captured?
- How are quotations prepared?
- How are markups calculated?
- How are suppliers confirmed?
- How are drivers and guides assigned?
- How are payments tracked?
- How are B2B agents managed?
- Which Excel sheets are business-critical?
- Which process causes the most revenue leakage?

Deliverables:

- Persona notes
- Workflow maps
- Pain point ranking
- MVP validation notes
- Sample quotation formats
- Sample itinerary formats
- Sample operations checklist

## Days 16-30: Product Design

Deliverables:

- PRD finalized
- Domain model finalized
- First database model
- API contracts
- Wireframes
- MVP acceptance criteria
- Tenant and permission model
- Technical architecture decisions

## Days 31-60: Foundation and CRM

Build:

- API project scaffold
- Admin web scaffold
- Authentication
- Organization and branch model
- Users, roles, permissions
- Lead CRUD
- Customer CRUD
- Lead assignment
- Tasks, follow-ups, notes
- Sales pipeline dashboard

## Days 61-90: Quotation and Itinerary

Build:

- Quotation CRUD
- Pricing engine
- Service line items
- Itinerary builder
- PDF generation
- Quotation send tracking
- Quotation acceptance
- Booking conversion
- Payment schedule
- Basic operations checklist

## Day 90 Outcome

A working demo that can be shown to travel agencies:

- Internal CRM
- Quotation builder
- Itinerary builder
- Booking conversion
- Payment tracking
- Basic dashboards
